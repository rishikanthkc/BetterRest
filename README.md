# BetterRest

BetterRest is an iOS application designed to help users predict their optimal bedtime based on modern sleep science. Built with Swift and SwiftUI, this project serves both as a learning resource and a practical wellness tool for Apple device users.

## Features

- Predicts ideal bedtimes using user input on sleep needs, coffee intake, and wake-up time.
- Modern SwiftUI interface for seamless user experience.
- Local data processing for privacy and speed.
- Modular Swift code for maintainability and reusability.


## Getting Started

1. Clone the repository:

```
git clone https://github.com/rishikanthkc/BetterRest.git
```

2. Open `BetterRest.xcodeproj` in Xcode (recommended Xcode version: 15+).
3. Build and run the app on a compatible iOS simulator or device.
4. Customize sleep prediction settings as needed to test various scenarios.

## Directory Structure

- **BetterRest.xcodeproj/** – Xcode project configuration.
- **BetterRest/** – Main source files and UI components.


## Technologies Used

- Swift 5
- SwiftUI
- Core Data (if applicable)
- Apple frameworks for date/time handling
